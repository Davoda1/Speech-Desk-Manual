These shortcuts are available in the desktop application. Playback and dictation actions still depend on the current task and whether a service or recording device is ready.

## Application shortcuts

| Shortcut | Action |
| --- | --- |
| **Ctrl+O** | Open a text file |
| **Ctrl+S** | Save the editor text |
| **Ctrl+Shift+S** | Save the completed reading as WAV |
| **Ctrl+Enter** | Speak, or pause/resume the active reading |
| **Ctrl+R** | Open dictation controls and start or stop recording |
| **Escape** | Cancel the active task |

## Editing and cancellation

Select text before choosing Speak to read only that passage. Place the cursor or select replacement text before starting dictation.

After successful dictation, **Ctrl+Z** undoes the inserted transcription in one action. Cancelling an active dictation restores the text and selection from before it began.

Audio export is available only after the complete reading has finished. The [playback guide](playback.html) explains playback controls, and the [dictation guide](dictation.html) covers recording and transcription.
